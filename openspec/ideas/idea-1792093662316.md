# artgen: scene composition that keeps the room pixel-exact

`generate --backend qwen_image21 --ref ROOM CHAR1 CHAR2` redraws the whole room, so it drifts slightly. The idea: `edit --image ROOM --ref CHAR1 CHAR2 --mask AREA --feather 8` so only the area where the characters go is taken from the model (paste-back, drift 0 outside the mask). Written into the artgen skill as untested.
